# Initializing Let's Encrypt https for dotori server
* If there is existing certificate, it will remove it!!!

1. Check your server's domain & port status.

2. makesure .env file is created and filled with proper values. 
- DOTORI_EXTERNAL_DOMAIN: example.com
- DOTORI_CERTIFICATE_EMAIL: your_email.com

Set these values in data/config/network_access/provider.env, not in the base .env file.

3. Initialize scripts are located in scripts/ folder. Run the following commands:
- chmod +x scripts/init_production_env.sh
- ./scripts/init_production_env.sh

# Optional but recommended
4. Let's encrypt certificates are managed by certbot container. It expires every 90 days.
    You can renew it by running the following commands:
    - chmod +x scripts/renew_certificates.sh
    - ./scripts/renew_certificates.sh
