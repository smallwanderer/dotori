# Dotori 시스템 아키텍처 (System Architecture)

해당 문서는 Dotori의 시스템 아키텍처에 대한 문서의 Entry point이다. 해당 문서에서는 하위 아키텍처 문서들에 대한 간략한 개요를 제공한다.

## 1.1. 목표

Dotori는 Self-hosting first 접근법으로 문서 분석 및 검색을 위한 경량화된 AI 플랫폼으로 개발 되었다.
핵심 설계 원칙은 다음과 같다:
- **Full-Stack**: 웹 UI부터 백엔드, 데이터 처리, 검색, RAG 실행까지 필요한 모든 계층을 하나의 제품으로 제공한다.
- **Modular**: 확장을 위해서 Domain-driven design(DDD)을 기반으로 모듈화되어야 한다. 
- **Lightweight**: 최소한의 자원으로 동작할 수 있도록 설계해야 한다.
- **Self-Hosted**: 서비스를 직접 호스팅하고 제어할 수 있도록 설계해야 한다.

이를 위해 Dotori는 여러 계층으로 구성되어 있으며, 각 계층은 독립적으로 분리 및 동작할 수 있도록 구성하였다.
