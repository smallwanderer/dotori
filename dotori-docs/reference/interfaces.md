# 인터페이스

> 이전: [동작 방식](../overview/how-it-works.md) · 다음: [연동 가이드](../guides/integrate/README.md)

이 문서는 Dotori와 상호작용하는 액터, 그들이 사용하는 경계 인터페이스와 인증, 그리고 Dotori가 연결하는 외부 시스템을 한곳에 모아 조회할 수 있게 합니다.

## 액터

| 액터 | 경계면 | 주고받는 것 |
| --- | --- | --- |
| 운영자 | 호스트 셸(설치 스크립트, Docker Compose) | 설치 모드와 초기 모델 구성을 입력하고, 운영 상태를 확인합니다. 런타임 세부 값을 수정할 수 있습니다 |
| 최종 사용자 | 웹 UI | 문서를 업로드하고 검색, 질문하며 처리 결과를 열람합니다. 세션 인증을 사용합니다 |
| CLI 사용자 | CLI API | 문서 목록, 결과 조회, 업로드, 검색, 스트리밍 질의를 수행합니다. 사용자별 토큰 인증을 사용합니다 |
| 로컬 폴더 동기화 클라이언트 | 동기화 API | 로컬 폴더와 서버 사이의 차이를 계산해 업로드, 생성, 삭제를 반영합니다. 별도의 인증을 사용합니다 |
| AI 에이전트 / MCP 호스트 | MCP 어댑터 | 준비된 결과를 AI에 제공합니다. 별도로 설치하는 읽기 전용 어댑터(`clients/dotori-mcp`)가 CLI API를 호출하며, 업로드·삭제·재시도 같은 변경 도구는 제공하지 않습니다 |

## 경계 인터페이스

| 인터페이스 | 인증 | 비고 |
| --- | --- | --- |
| 웹 UI 및 브라우저 API | 세션 + CSRF | SPA는 백엔드와 같은 출처에서 제공됩니다 |
| CLI API | 사용자별 Bearer 토큰 | 동반 CLI와 MCP 어댑터가 공통으로 사용하는 표면입니다 |
| 동기화 API | Bearer 토큰 | 로컬 폴더 동기화 전용 경로입니다 |
| 관리자 화면 | 세션 | 운영자용 최소 표면입니다 |
| API 문서 | 없음 | 스키마만 제공합니다 |

공개 지점은 하나로 제한됩니다. 애플리케이션 프로세스는 루프백 주소에만 포트를 발행하며, 외부 HTTPS 종단은 선택적인 리버스 프록시 프로파일을 켤 때만 열립니다. executor는 Dotori 내부 네트워크에서만 접근할 수 있는 내부 구성요소이며 호스트 인터페이스를 노출하지 않습니다. 따라서 시스템 경계를 넘는 상호작용이 아니어서 이 표에 나타내지 않습니다. 요청과 응답의 정확한 형식은 [API 계약](./api-contract-v1.md)에 있습니다.

## 외부 시스템

Dotori는 기본적으로 운영자가 관리하는 단일 서버에서 동작하며 선택한 기능에 따라 외부 시스템과 연결됩니다.

| 시스템 | 용도 | 비고 |
| --- | --- | --- |
| 모델 레지스트리 | 설치 또는 명시적인 모델 변경 | 모델 가중치를 취득합니다. 가중치를 미리 확보한 환경에서는 오프라인 스위치로 차단할 수 있습니다 |
| 컨테이너 이미지 레지스트리 | 설치 및 업데이트 시점 | 기반 이미지를 취득합니다 |
| 외부 추론 엔드포인트 | 운영자가 선택한 경우에만 | 운영자가 외부 임베딩 또는 LLM 모델을 선택한 경우 추론 요청을 전달합니다 |
| 인증서 발급 기관 | HTTPS 구성을 선택한 경우에만 | 인증서를 발급 및 갱신합니다 |
