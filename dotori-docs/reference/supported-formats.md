# 지원하는 파일 형식

> 이전: [Dotori란 무엇인가](../overview/what-is-dotori.md)

이 문서는 업로드한 파일 가운데 문서 분석(파싱) 대상이 되는 확장자를 모아 둡니다. 확장자는 파일 이름으로 판정합니다. 목록에 없는 확장자는 업로드는 되지만 분석 대상에서 제외되고 원본 보관용으로만 쓰입니다.

| 종류 | 확장자 |
| --- | --- |
| 문서와 오피스 | `.pdf`, `.docx`, `.pptx`, `.xlsx`, `.hwp`, `.hwpx` |
| 텍스트와 마크다운 | `.txt`, `.md`, `.markdown` |
| 웹과 설정 | `.html`, `.htm`, `.xml`, `.json`, `.yaml`, `.yml`, `.toml`, `.ini`, `.cfg`, `.conf` |
| 소스 코드 | `.py`, `.js`, `.ts`, `.sh`, `.bash`, `.sql` |
| 이미지 | `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.tiff`, `.gif` |

- 이미지 파일은 이미지 분석이 아니라 문서와 같은 방식으로 글자를 추출합니다.
- 설치 모드가 기본이면 파일 관리만 하므로 어떤 확장자도 분석하지 않습니다([동작 방식](../overview/how-it-works.md#설치-모드에-따라-무엇이-켜지나요)).
- 이 목록은 서버가 초기 작업을 만들 때 쓰는 기준입니다([등록부](../architecture/blocks/registry.md#입력-라우팅)). 실제 파싱이 성공하는지는 파일 내용에 따라 다릅니다.
